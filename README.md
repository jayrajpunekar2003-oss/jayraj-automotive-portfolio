# Midnight Executive — Jayraj Punekar

A responsive automotive design engineering portfolio built with React, Vite, TypeScript, Three.js, and React Three Fiber.

## Run locally

```sh
npm install
npm run dev
```

Create a production build with `npm run build`, then preview it with `npm run preview`.

## Editable profile and project content

Update `src/data.ts` to edit profile links, email, resume URL, skills, project studies, and engineering viewer notes. The email is configured, and the supplied resume PDF is served from `public/Jayraj-Punekar-Resume.pdf`.

The project cards are explicitly presented as independent portfolio practice studies; they do not assert OEM affiliation, production validation, or completed employer projects. The door map pocket and armrest are grouped under the door trim study.

## 3D Models

The interactive 3D Models section uses procedural demonstration cars and illustrative interior-component geometries. They are not manufacturer CAD, CATIA exports, or representations of Jayraj's completed CAD work.

Use the model selector to switch models, drag to orbit, scroll to zoom, or use the view controls to reset, change the display mode, and enter fullscreen. GLB and GLTF files can be loaded locally through the upload control. Self-contained `.gltf` files with embedded resources are supported; use GLB for models with external buffers or textures. Native CATIA files must be converted to a supported format before viewing.

The page background includes a pointer-reactive animated plexus effect. The displayed engineering notes explain general design considerations and are not model-attached annotations or production guidance.

## Projects

The first three portfolio entries summarize AutoOne Engineering project work shared by Jayraj. The separate door-trim practice study includes expandable Door Map Pocket and Automotive Armrest design notes.

## Terminal

The JAYRAJ.OS command prompt is a safe, local portfolio interface. It supports `help`, `about`, `whoami`, `skills`, `projects`, `project 1`, `project 2`, `project 3`, `project 4.1`, `project 4.2`, `experience`, `education`, `models`, `contact`, `linkedin`, `date`, and `clear`. It does not execute operating-system commands.
